# أهل الدولة — التاريخ كما يرويه صُنّاعه

عرض تقديمي تفاعلي (10 شرائح) للمقترح التحريري والإنتاجي للحلقة الأولى، لصالح شركة ثلاثون لقطة للإنتاج والتوزيع الفني.

## النشر على Netlify
الملف `index.html` مستقل بذاته، وتجاوره الصور (`hero.jpg`, `dialogue.jpg`, `archives.jpg`, `pillars.jpg`, `logo.png`). اربط المستودع بـ Netlify بدون أي أمر بناء، ودليل النشر هو الجذر `/`.

## التنقل
عجلة الفأرة، السحب، الأسهم، أو شريط التحكم السفلي (الفهرس وملء الشاشة).
